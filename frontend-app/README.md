# Fitness Platform App 前端（App 端）

## 启动
1. 安装依赖
   ```bash
   cd frontend-app
   npm install
   ```
2. 启动开发服务
   ```bash
   npm run dev
   ```

默认访问地址：`http://localhost:5174/`  
代理转发：`/app -> http://localhost:8093`

> 如提示 `无法连接后端`，请确认 `web-app` 已启动在 8093。

## 登录
建议账号：`root`  
建议密码：`root`  
（其他账号以数据库为准）
