# 查看 / 关闭 admin/app（先整段执行一次，后面直接用 shw / khw）
$HuangWebPorts = 8080,8081,8083,8084
$HuangWebPatterns = @(
  'com\.huang\.web\.app\.AppWebApplication',
  'com\.huang\.web\.admin\.AdminWebApplication',
  'spring-boot:run.+web[\\/]+web-app',
  'spring-boot:run.+web[\\/]+web-admin',
  'web[\\/]+web-app[\\/]+target[\\/]+classes',
  'web[\\/]+web-admin[\\/]+target[\\/]+classes'
)
function Test-HuangWebCmdLine {
  param([string]$CommandLine)
  foreach ($pattern in $HuangWebPatterns) {
    if ($CommandLine -match $pattern) { return $true }
  }
  return $false
}
function Get-HuangWebPid {
  $pids = [System.Collections.Generic.HashSet[int]]::new()
  Get-NetTCPConnection -LocalPort $HuangWebPorts -State Listen -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty OwningProcess -Unique |
    ForEach-Object { [void]$pids.Add([int]$_) }
  Get-CimInstance Win32_Process |
    Where-Object { $_.CommandLine -and (Test-HuangWebCmdLine $_.CommandLine) } |
    ForEach-Object {
      [void]$pids.Add([int]$_.ProcessId)
      if ($_.ParentProcessId -gt 0) { [void]$pids.Add([int]$_.ParentProcessId) }
    }
  @($pids) | Sort-Object -Unique
}
function Show-HuangWeb {
  $ids = Get-HuangWebPid
  if (-not $ids) { Write-Host '没有找到 web-app / web-admin 相关进程'; return }
  Get-CimInstance Win32_Process |
    Where-Object { $ids -contains [int]$_.ProcessId } |
    Select-Object ProcessId, ParentProcessId, Name, CommandLine |
    Format-Table -Wrap
}
function Stop-HuangWeb {
  $ids = Get-HuangWebPid
  if (-not $ids) { Write-Host '没有找到 web-app / web-admin 相关进程'; return }
  $ids | Sort-Object -Descending | ForEach-Object {
    try {
      $proc = Get-Process -Id $_ -ErrorAction Stop
      Stop-Process -Id $_ -Force -ErrorAction Stop
      Write-Host "已停止 PID=$($_) 进程=$($proc.ProcessName)"
    } catch {
      Write-Warning "停止 PID=$($_) 失败: $($_.Exception.Message)"
    }
  }
}
Set-Alias shw Show-HuangWeb
Set-Alias khw Stop-HuangWeb
