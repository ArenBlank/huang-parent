## 3. 推荐测试顺序
1. 先重置测试数据：`powershell -ExecutionPolicy Bypass -File tests/reset-test-data.ps1`
2. 登录管理端，先看权限中心、看板、内容运营。
3. 在管理端新增 Banner、公告、系统配置，给用户端首页做联动验证。
4. 在管理端上传视频、创建视频素材、绑定训练计划项。
5. 在管理端创建课程、上架课程、创建课程排期。
6. 登录用户端，验证首页内容、训练计划列表、计划详情里的视频地址。
7. 在用户端订阅计划，再做一次打卡。
8. 在用户端创建预约单，完成支付回调，再到管理端验证预约运维。
9. 在管理端执行授课完成或关闭超时预约。
10. 在用户端完成课程报名、模拟支付成功、发起退款。
11. 在管理端验证退款审计、支付回调审计、订单详情。
12. 在用户端修改个人资料和密码。
13. 在用户端提交教练申请，再到管理端审核。
14. 最后验证用户角色、角色范围、角色权限、权限矩阵这些后台页面。

## 5. 管理端页面测试

### `/login`
- 目标：拿到管理端 token，进入后台页面。
- 接口：
  - `POST /admin/auth/login`
  - 对应 Postman：`01A Admin Login`
- 请求体示例：
  ```json
  {
    "account": "admin",
    "password": "$2a$10$demoAdminPasswordHash"
  }
  ```
- 成功校验：
  - 浏览器本地存储里有 `fitness_admin_token`
  - 页面跳到 `/permission-center`

### `/permission-center`
- 目标：验证权限矩阵同步、角色分权、操作日志联动。
- 接口：
  - `GET /admin/permission/matrix`
  - `GET /admin/role/list`
  - `GET /admin/role-permission/permissions`
  - `GET /admin/operation-log/list?module=permission_matrix&limit=20`
  - `GET /admin/operation-log/list?module=role_permission&limit=20`
  - `POST /admin/permission/matrix/sync`
  - `POST /admin/role-permission/assign`
- 对应 Postman：
  - `76 Admin Permission Matrix`
  - `33 Admin Role List`
  - `33E Admin Permission List`
  - `33F Admin Role Permission List`
  - `33G Admin Assign Role Permissions (Add)`
  - `33H Verify Role Permission Operation Log`
- 重点怎么测：
  - 先点同步矩阵，再给一个角色分配权限。
  - 看页面数据和操作日志是否一起刷新。

### `/dashboard`

- 成功校验：
  - 看板卡片正常加载，没有 401 和 500。

### `/content`
- 目标：管理 Banner、公告、系统配置，并联动验证用户端首页。
- 接口：
  - `GET /admin/banner/list`
  - `POST /admin/banner`
  - `PUT /admin/banner/{id}`
  - `PUT /admin/banner/{id}/status`
  - `DELETE /admin/banner/{id}`
  - `GET /admin/notice/list`
  - `POST /admin/notice`
  - `PUT /admin/notice/{id}`
  - `PUT /admin/notice/{id}/status`
  - `DELETE /admin/notice/{id}`
  - `GET /admin/system-config/list`
  - `POST /admin/system-config`
  - `PUT /admin/system-config/{id}`
  - `DELETE /admin/system-config/{id}`
- 对应 Postman：
  - `22 Admin Create Banner` to `27 App System Config Map`
  - `44 Admin Banner List` to `54A Verify System Config Delete Operation Log`
- 重点怎么测：
  - 分别新增 1 条 Banner、1 条公告、1 条系统配置。
  - 各改一次，支持上下架的做一次状态切换，再删除。
  - 打开用户端 `/home` 验证 Banner 和公告是否能看到。
