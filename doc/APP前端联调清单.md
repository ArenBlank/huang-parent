# APP 前端联调清单（V3）

## 1. 前置条件
- 启动后端：`web-admin` (8080) 与 `web-app` (8081)
- 启动中间件（MySQL/Redis/MinIO 等）
- 启动前端：
  - 管理端：`frontend` -> `npm run dev` -> http://localhost:5173
  - APP 端：`frontend-app` -> `npm run dev` -> http://localhost:5174

## 3. 必跑链路（建议顺序）
### 3.1 登录
- 页面：APP 登录页
- 操作：输入账号/密码登录
- 预期：进入首页 /home

### 3.2 首页 Banner + 公告
- 页面：首页
- 操作：点击刷新
- 预期：Banner 列表与公告可见（无数据时显示“暂无”）

### 3.3 训练计划
- 页面：计划
- 操作：
  - 列表加载
  - 点击任意计划 -> 查看详情
  - 选择开始日期 -> 订阅
- 预期：订阅成功（无权限/未登录会提示）

### 3.4 课程报名
- 页面：课程
- 操作：
  - 课程列表加载
  - 点击课程 -> 载入排期
  - 选择排期 -> 提交报名
  - 刷新“我的报名”
- 预期：报名成功并可在“我的报名”中看到记录

### 3.5 预约教练
- 页面：预约
- 操作：
  - 查询可预约档期（教练ID=2）
  - 选择档期 -> 提交预约
  - 刷新“我的预约”
- 预期：预约成功，记录出现在列表

### 3.6 训练打卡
- 页面：打卡
- 操作：
  - 查看周统计
  - 填写计划ID/计划项ID/日期 -> 提交打卡
  - 刷新“我的打卡记录”
- 预期：打卡成功，记录新增

### 3.7 订单查询
- 页面：订单
- 操作：输入订单ID -> 查询
- 预期：返回订单详情（含金额/状态字段）

### 3.8 个人资料
- 页面：我的
- 操作：
  - 查看资料
  - 修改昵称/邮箱/地址 -> 保存
  - 修改密码 -> 提交
- 预期：保存/修改提示成功

## 4. 常见问题
- 登录失败：检查账号/密码是否匹配测试数据
- 无数据：先通过管理端创建课程/排期/视频素材
- 预约失败：可能档期已满，执行测试数据重置后再试

## 5. 推荐补齐数据（管理端）
- 课程：创建课程 -> 上架 -> 创建排期
- 视频：上传 -> 新建素材 -> 绑定计划项
- 运营：创建 Banner / 公告 / 系统配置
