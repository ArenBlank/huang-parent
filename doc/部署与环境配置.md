# 部署与环境配置

## 1. 多环境配置
- 已新增 `dev`、`test`、`prod` 三套 Spring Profile。
- 默认使用：
  - `SPRING_PROFILES_ACTIVE` 未设置时，默认走 `dev`

配置文件位置：
- `web/web-admin/src/main/resources/application-dev.yml`
- `web/web-admin/src/main/resources/application-test.yml`
- `web/web-admin/src/main/resources/application-prod.yml`
- `web/web-app/src/main/resources/application-dev.yml`
- `web/web-app/src/main/resources/application-test.yml`
- `web/web-app/src/main/resources/application-prod.yml`

## 2. 关键环境变量
生产环境至少需要显式提供以下变量：

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `REDIS_HOST`
- `REDIS_PORT`
- `REDIS_PASSWORD`
- `REDIS_DATABASE`
- `MINIO_ENDPOINT`
- `MINIO_ACCESS_KEY`
- `MINIO_SECRET_KEY`
- `MINIO_BUCKET`
- `ADMIN_PORT`
- `APP_PORT`

说明：
- `test` 环境支持大部分变量带默认值，便于本地或 CI 运行。
- `prod` 环境不再为数据库、MinIO 等敏感配置提供完整默认值，避免误连。

## 3. 启停方式
统一使用项目根目录下的 `start_or_stop.txt`。

如果要以生产配置启动，可在命令中指定 profile：

```powershell
mvn -f web/web-admin/pom.xml -Dspring-boot.run.profiles=prod spring-boot:run
mvn -f web/web-app/pom.xml -Dspring-boot.run.profiles=prod spring-boot:run
```

## 4. Nginx 反向代理
Nginx 模板文件：

- `deploy/nginx/fitness.conf`

当前代理规则：
- `/admin/**` -> `8080`
- `/app/**` -> `8081`
- `/v3/api-docs/admin` -> admin OpenAPI
- `/v3/api-docs/app` -> app OpenAPI
- `/doc/admin` -> admin Knife4j
- `/doc/app` -> app Knife4j

将 `deploy/nginx/fitness.conf` 挂载到 Nginx 的 `conf.d` 后，重载 Nginx 即可生效。
