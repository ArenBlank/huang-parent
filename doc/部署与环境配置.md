# 部署与环境配置

## 1. Spring Profile

项目当前提供三套 Spring Profile：

- `dev`
- `test`
- `prod`

配置文件位置：

- `web/web-admin/src/main/resources/application.yml`
- `web/web-admin/src/main/resources/application-dev.yml`
- `web/web-admin/src/main/resources/application-test.yml`
- `web/web-admin/src/main/resources/application-prod.yml`
- `web/web-app/src/main/resources/application.yml`
- `web/web-app/src/main/resources/application-dev.yml`
- `web/web-app/src/main/resources/application-test.yml`
- `web/web-app/src/main/resources/application-prod.yml`

默认未设置 `SPRING_PROFILES_ACTIVE` 时使用 `dev`。

## 2. 当前本地部署结构

### 2.1 服务端口

- Admin：`8080`
- App 实例一：`8081`
- App 实例二：`8082`
- MySQL：`3306`
- Redis：`6379`
- MinIO API：`9000`
- MinIO Console：`9001`
- Nginx：`80`

### 2.2 域名约定

- `app.localhost`
- `admin.localhost`
- `files.localhost`

未配置本机 `hosts` 时：

- 辅助脚本可直接走 `http://localhost` + `Host` 头
- 如果希望浏览器直接访问域名，可在本机 `hosts` 中添加：
  - `127.0.0.1 app.localhost`
  - `127.0.0.1 admin.localhost`
  - `127.0.0.1 files.localhost`

## 7. 当前缓存失效相关配置

Admin 和 App 都统一补齐了：

```yml
spring:
  application:
    name: fitness-admin # 或 fitness-app

app:
  instance-id: ${spring.application.name}:${server.port}

cache:
  invalidation:
    channel: cache:evict
```

说明：

- `instance-id` 用于区分消息发布来源
- Redis Pub/Sub channel 固定为 `cache:evict`
- 各实例订阅后仅清自己的本地缓存

## 8. 当前 JWT 相关配置语义

项目当前采用 `TokenVersion-enhanced stateless JWT`：

- Admin / App 均签发 `accessToken + refreshToken`
- token 中包含平台和 tokenVersion 信息
- 密码重置会递增 `token_version`
- 账号禁用依赖 `status=0` 立即失效

## 9. 当前支付验签模式

`web/web-app` 支持支付签名模式切换：

```yml
payment:
  sign:
    mode: mock   # mock / hmac
    secret: ""
```

说明：

- `mock`：本地演示模式
- `hmac`：CI 和集成回归模式
