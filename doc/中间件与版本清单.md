# 中间件与版本清单

> 说明：以下为“建议版本”与“可选版本区间”，以稳定性与学习成本为优先。部署时尽量与服务器环境保持一致。

| 组件 | 用途 | 版本建议 | 说明 |
|---|---|---|---|
| MySQL | 主业务数据库 | 8.0.x | 选择 8.0 分支的稳定版本，满足 JSON、窗口函数与性能优化需求。 |
| Redis | 缓存/验证码/限流 | 7.2.x | 支持现代数据结构与更高性能，适合做登录态与短期缓存。 |
| MinIO Server | 对象存储 | RELEASE.2025-10-15T17-29-55Z | 用于头像、课程封面、训练视频与打卡图片。 |
| Docker Compose | 单机部署编排 | v2（Compose Specification） | 服务器建议使用 Docker Engine + Compose 插件方式部署。 |
